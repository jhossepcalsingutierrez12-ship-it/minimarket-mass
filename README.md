# Minimarket Mass

Sistema de base de datos para la gestión de ventas, pagos, cajas y stock
de un minimarket con tres tiendas en Arequipa.

## Estructura
- `docs/`: diagrama ER y modelo de Workbench
- `database/`: schema.sql, datos.sql y consultas.sql
